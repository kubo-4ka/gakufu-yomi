# 楽譜よみ練習帳

ト音記号・ヘ音記号の五線譜を、ぱっと読めるようになるための練習用の静的 Web アプリです。
音の一覧・五線譜クイズ・聴き取りクイズ・鍵盤を使って、毎日少しずつ練習できます。
HTML / CSS / JavaScript だけで動きます（ビルド不要）。

# DEMO

https://kubo-4ka.github.io/gakufu-yomi/

## 機能

画面下のメニューで 5 つの画面を切り替えます。

- **クイズ**（5／10／20／30／50 問）
  - 五線譜を読む：音符を見て、音名をボタン（ド〜シの 7 つ）で答える
  - 鍵盤で答える：音符を見て、鍵盤の正しい場所を押す（オクターブまで区別）
  - 五線譜から探す：「ト音記号のソ」を見て、4 つの五線譜から選ぶ
  - 聴いて五線譜を選ぶ：鳴った音の五線譜を選ぶ（選択肢は「離れた音」「近い音」から選べる）
  - 聴いて音名を答える：鳴った音の名前を答える（「先に基準のドを鳴らす」オプションあり）
  - 60 秒スピード読み：60 秒で何問読めるか。設定ごとに自己ベストを記録
  - 記号：ト音記号／ヘ音記号／両方／大譜表。音域：五線の中だけ／加線なし〜加線 3 本まで。♯・♭ の有無
  - 出題する音：すべて／線の上の音だけ／線の間の音だけ／ドミソだけ
  - 1 問で読む音の数：1 つ・2 つ・3 つ（左から順に答える。五線譜を選ぶ問題は音の並びごと選ぶ）
  - ステップ：ドミソ → 線の音 → 間の音 → 五線の中ぜんぶ → 2 つ続けて → 加線 1 本 → ヘ音記号 → 大譜表 → 3 つ続けて → ♯・♭ の 12 段階。押すと設定がまとめて切り替わる
  - 間違えた音を多めに出す、正解したら自動で次へ、結果画面から「間違えた音だけ」再挑戦
  - クイズ中はヘッダーとメニューを隠し、スマホでもスクロールせずに進められるレイアウト
  - キーボード操作：1〜7 / C〜B で回答、Enter で次へ、Space でもう一度聴く、Esc でやめる
  - 今日の問題数・1 日の目標・連続練習日数をクイズの画面の上に表示
- **一覧**：ト音記号・ヘ音記号の音（加線 3 本まで、♯・♭ も表示可）。目印の音（ト音記号のソ・真ん中のド・ヘ音記号のファなど）、線と間の音の並び、音名の対応表（ドレミ／CDE／ハニホ／ドイツ式）。カードをタップで音が鳴る。「音名を隠す」で暗記カードとしても使える
- **鍵盤**：C2〜C6 の鍵盤。押した音が大譜表のどこに書かれるか、各表記での名前、日本式のオクターブ名（一点ハ など）を表示
- **記録**：連続練習日数、今日・累計の問題数と正答率、2 週間の棒グラフ、苦手な音（そこから練習を開始できる）、音ごとの正答率、スピード読みの自己ベスト
- **説明**：使い方、読み方のコツ、音名の表記、クレジット
- 音名の表記：ドレミ（イタリア式）／CDE（英米式）／ハニホ（日本式）／ドイツ式（H・B、Fis・Es など）
- 音色：ピアノ／純音（サイン波）／オルガン／シンセ／ストリングス／オルゴール（Web Audio API で合成、音声ファイル不要）。純音・オルガン・シンセ・ストリングスは持続音で、長さを設定でき、鍵盤は押している間のびる
- ホーム画面に追加してアプリとして使える（PWA）。オフラインで動くのは https:// か localhost で配信した場合のみ
- ライト／ダークテーマ（初回は OS の設定に従う）

## ファイル構成

| ファイル                                    | 内容                                                                          |
| ------------------------------------------- | ----------------------------------------------------------------------------- |
| `index.html`                                | 画面                                                                          |
| `style.css`                                 | デザイン（色は `:root` のトークンで管理）                                     |
| `music.js`                                  | 音の理論（音名・音域）、五線譜の SVG 描画、鍵盤、音源（`window.Music`）       |
| `app.js`                                    | アプリ本体（クイズ・一覧・鍵盤・記録）                                        |
| `manifest.webmanifest` / `sw.js` / `icons/` | アプリとしてインストールするための設定・オフライン用キャッシュ・アイコン      |
| `tools/serve.js`                            | ローカル確認用サーバ（`node tools/serve.js` → http://localhost:26836）        |
| `tools/make-cert.js`                        | スマホから HTTPS で確認するための自己署名証明書を作るスクリプト（要 openssl） |

### 五線譜の描き方

- 音符・加線・♯♭・大譜表の括弧は `music.js` の `staffSVG()` が SVG で描いています
- ト音記号・ヘ音記号だけはフォント（Noto Music、Google Fonts から 2 文字分だけ読み込み）の字形を使い、Canvas でインクの上下端を実測して、五線の決まった位置（ト音記号の渦巻きが第 2 線、ヘ音記号の点が第 4 線をはさむ位置）に合わせて拡大しています。フォントが読み込めない環境でも、OS の記号フォントで同じ位置に収まります
- 音域は「加線 n 本まで」で、加線なしで書けるすぐ外の音（ト音記号の下のレ・上のソなど）も含みます

## ローカルで動かす

```bash
node tools/serve.js
```

http://localhost:26836/ を開きます。スマホから Service Worker（オフライン・ホーム画面アプリ）を試すときは、`node tools/make-cert.js` で証明書を作ってから `node tools/serve.js --https` で起動してください。iPhone では Safari で `http://<PCのIP>:26837/cert.cer` を開いて証明書をインストールし、設定 → 一般 → 情報 → 証明書信頼設定 でオンにしてから `https://<PCのIP>:26836/` を開きます。`tools/certs/` は秘密鍵を含むため `.gitignore` で除外しています。

### 更新するとき

ファイルを変更したら、`sw.js` の `VERSION`（例：`gy-v1` → `gy-v2`）を上げてください。インストール済みのアプリにも更新が届きます。

## データの保存

正答率・練習した日・自己ベスト・設定は、ブラウザの localStorage（キーの先頭は `gy.`）だけに保存します。外部へは送信しません。

- フォント：Shippori Mincho / Zen Kaku Gothic New / Cormorant Garamond（Google Fonts, SIL Open Font License）
